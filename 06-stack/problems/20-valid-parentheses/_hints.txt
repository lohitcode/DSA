## Hint 1/2
Use a stack. Push opening brackets.

## Hint 2/2
Pop and match when closing bracket appears.

## Solution
```go
func isValid(s string) bool {
    stack := []rune{}
    matching := map[rune]rune{')': '(', '}': '{', ']': '['}
    for _, c := range s {
        if c == '(' || c == '{' || c == '[' {
            stack = append(stack, c)
        } else {
            if len(stack) == 0 || stack[len(stack)-1] != matching[c] {
                return false
            }
            stack = stack[:len(stack)-1]
        }
    }
    return len(stack) == 0
}
```
