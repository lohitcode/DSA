# Dynamic Programming 2D

## 🎯 The Core Idea

2D DP is like 1D DP, but your state depends on **two dimensions** — usually a grid or two strings. Instead of `dp[i]`, you have `dp[i][j]`.

**> Quick thought**: When do you need 2D instead of 1D?

<details>
<summary>Click to reveal...</summary>

When your problem involves grids, paths on grids, or comparing TWO sequences (strings, arrays). Each cell `dp[i][j]` represents a subproblem.
</details>

## 🔥 Common 2D DP Patterns

### Pattern 1: Unique Paths (Grid)
**> How many ways from top-left to bottom-right?**

```go
func uniquePaths(m, n int) int {
    dp := make([][]int, m)
    for i := range dp {
        dp[i] = make([]int, n)
        dp[i][0] = 1  // Only one way: straight down
    }
    for j := 1; j < n; j++ {
        dp[0][j] = 1  // Only one way: straight right
    }
    
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            // Ways from above + ways from left
            dp[i][j] = dp[i-1][j] + dp[i][j-1]
        }
    }
    
    return dp[m-1][n-1]
}
```

**Key insight**: At each cell, you can only arrive from above OR from the left.

---

### Pattern 2: Min Path Sum (Grid with Weights)
**> Find path with minimum sum**

```go
func minPathSum(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    dp := make([][]int, m)
    for i := range dp {
        dp[i] = make([]int, n)
    }
    
    // Base case: top-left
    dp[0][0] = grid[0][0]
    
    // First row: can only come from left
    for j := 1; j < n; j++ {
        dp[0][j] = dp[0][j-1] + grid[0][j]
    }
    
    // First column: can only come from above
    for i := 1; i < m; i++ {
        dp[i][0] = dp[i-1][0] + grid[i][0]
    }
    
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            // Min of (from above) or (from left)
            dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
        }
    }
    
    return dp[m-1][n-1]
}
```

**Key insight**: Take the minimum of the two possible paths to reach each cell.

### Pattern 3: Longest Common Subsequence (Two Strings)
**> Longest sequence appearing in both strings (not necessarily contiguous)**

```go
func longestCommonSubsequence(text1, text2 string) int {
    m, n := len(text1), len(text2)
    dp := make([][]int, m+1)
    for i := range dp {
        dp[i] = make([]int, n+1)
    }
    
    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ {
            if text1[i-1] == text2[j-1] {
                // Characters match: extend LCS
                dp[i][j] = dp[i-1][j-1] + 1
            } else {
                // No match: take max of skipping one char
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
            }
        }
    }
    
    return dp[m][n]
}
```

**Visual**:
```
     ""  A  B  C  D
""    0  0  0  0  0
A     0  1  1  1  1
B     0  1  2  2  2
C     0  1  2  3  3

dp[i][j] = LCS of text1[0:i] and text2[0:j]
```

**Key insight**: If characters match, add 1 to diagonal. If not, take max of left or up.

### Pattern 4: Edit Distance (Two Strings)
**> Minimum operations to convert one string to another**

```go
func minDistance(word1, word2 string) int {
    m, n := len(word1), len(word2)
    dp := make([][]int, m+1)
    for i := range dp {
        dp[i] = make([]int, n+1)
    }
    
    // Base cases: convert to/from empty string
    for i := 0; i <= m; i++ {
        dp[i][0] = i  // Delete all characters
    }
    for j := 0; j <= n; j++ {
        dp[0][j] = j  // Insert all characters
    }
    
    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ {
            if word1[i-1] == word2[j-1] {
                dp[i][j] = dp[i-1][j-1]  // No operation needed
            } else {
                // 1 + min(insert, delete, replace)
                dp[i][j] = 1 + min(
                    dp[i][j-1],    // Insert
                    dp[i-1][j],    // Delete
                    dp[i-1][j-1],  // Replace
                )
            }
        }
    }
    
    return dp[m][n]
}
```

### Pattern 5: Palindrome Substrings
**> Longest palindromic subsequence**

```go
func longestPalindromeSubseq(s string) int {
    n := len(s)
    dp := make([][]int, n)
    for i := range dp {
        dp[i] = make([]int, n)
        dp[i][i] = 1  // Single char is palindrome
    }
    
    // Build from smaller to larger substrings
    for length := 2; length <= n; length++ {
        for i := 0; i <= n-length; i++ {
            j := i + length - 1
            if s[i] == s[j] {
                if length == 2 {
                    dp[i][j] = 2
                } else {
                    dp[i][j] = dp[i+1][j-1] + 2
                }
            } else {
                dp[i][j] = max(dp[i+1][j], dp[i][j-1])
            }
        }
    }
    
    return dp[0][n-1]
}
```

**Key insight**: For palindromes, expand from center and check if ends match.

## 🎮 Practice Exercise

**> Problem**: Given a grid with obstacles, count unique paths from top-left to bottom-right. Obstacle = 1, empty = 0.

<details>
<summary>Think about how to handle obstacles...</summary>

If grid[i][j] == 1 (obstacle), dp[i][j] = 0 (can't reach).
</details>

<details>
<summary>Solution</summary>

```go
func uniquePathsWithObstacles(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    
    // If start or end is blocked
    if grid[0][0] == 1 || grid[m-1][n-1] == 1 {
        return 0
    }
    
    dp := make([][]int, m)
    for i := range dp {
        dp[i] = make([]int, n)
    }
    dp[0][0] = 1
    
    // First row
    for j := 1; j < n; j++ {
        if grid[0][j] == 0 {
            dp[0][j] = dp[0][j-1]
        }
    }
    
    // First column
    for i := 1; i < m; i++ {
        if grid[i][0] == 0 {
            dp[i][0] = dp[i-1][0]
        }
    }
    
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            if grid[i][j] == 0 {
                dp[i][j] = dp[i-1][j] + dp[i][j-1]
            }
        }
    }
    
    return dp[m-1][n-1]
}
```
</details>

## 💡 Space Optimization

Most 2D DP problems can be reduced to O(n) space:

```go
// Before: O(m × n) space
dp := make([][]int, m)

// After: O(n) space
dp := make([]int, n)
prev := make([]int, n)

for i := 0; i < m; i++ {
    for j := 0; j < n; j++ {
        if i == 0 && j == 0 {
            dp[j] = 1
        } else if i == 0 {
            dp[j] = dp[j-1]
        } else if j == 0 {
            dp[j] = prev[j]
        } else {
            dp[j] = prev[j] + dp[j-1]
        }
    }
    prev, dp = dp, make([]int, n)
}
```

**When you can optimize**: If `dp[i][j]` only depends on previous row (`i-1`) and current row.

| Pattern | Time | Space |
|---------|------|-------|
| Grid paths | O(m × n) | O(m × n) → O(n) |
| String LCS | O(m × n) | O(m × n) → O(n) |
| Edit distance | O(m × n) | O(m × n) → O(n) |

## ⚠️ Common Pitfalls

1. **Off-by-one indices**: `dp[i][j]` corresponds to `grid[i-1][j-1]` for string problems
2. **Base cases**: First row/column often need special handling
3. **Initialization order**: Process cells in correct dependency order
4. **Integer overflow**: Use `int64` for large results
5. **Space**: Not all problems can be space-optimized

---

## 🚀 When to Use 2D DP

✅ **Use 2D DP when:**
- Problems involve grids/paths on grids
- Comparing two sequences (strings)
- State depends on two dimensions
- Can be broken into overlapping subproblems

---

## 📋 2D DP Framework

1. **Define state**: What does `dp[i][j]` represent?
2. **Find recurrence**: How to compute `dp[i][j]` from previous states?
3. **Base cases**: What are the simplest subproblems?
4. **Iteration order**: In what order to fill the table?
5. **Return answer**: Which cell holds the final answer?
