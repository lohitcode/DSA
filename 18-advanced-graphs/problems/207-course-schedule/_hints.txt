## Hint 1/3
This is a cycle detection problem in a directed graph. Build an adjacency list from prerequisites.

## Hint 2/3
Use DFS with three states: unvisited (0), visiting (1), visited (2). If we encounter a node in "visiting" state, there's a cycle.

## Hint 3/3
Alternatively, use topological sort with Kahn's algorithm (BFS with indegree). Count visited nodes.
