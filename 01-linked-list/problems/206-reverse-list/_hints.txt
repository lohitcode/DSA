# Hints for 206. Reverse Linked List

## Hint 1/3
You need to reverse the **pointers**, not swap values. As you traverse the list, make each node point to its previous node instead of its next node.

## Hint 2/3
Use three pointers:
- `prev` - starts at nil, tracks the reversed portion
- `curr` - starts at head, the node being processed
- `next` - temporarily stores curr.Next so we don't lose it

## Hint 3/3
Inside the loop:
1. `next = curr.Next` - Save next node
2. `curr.Next = prev` - Reverse the pointer
3. `prev = curr` - Move prev forward
4. `curr = next` - Move curr forward

Return `prev` as the new head (it was the last node).

---

## Solution

```go
func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    curr := head

    for curr != nil {
        next := curr.Next
        curr.Next = prev
        prev = curr
        curr = next
    }

    return prev
}
```
