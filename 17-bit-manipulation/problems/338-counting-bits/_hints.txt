## Hint 1/3
For each number from 0 to n, count the set bits. This is O(n log n).

## Hint 2/3
Notice pattern: `bits[i] = bits[i/2] + (i % 2)`. The rightmost bit of i is `i % 2`, and the rest is `i/2`.

## Hint 3/3
Dynamic programming: For any number i, remove the rightmost bit using `i & (i-1)` and add 1 to the result of that smaller number.

## Solution
```go
func countBits(n int) []int {
    bits := make([]int, n+1)
    for i := 1; i <= n; i++ {
        bits[i] = bits[i>>1] + (i & 1)
    }
    return bits
}
```
