## Hint 1/3
Check each bit of the number one by one. Use a loop that runs 32 times.

## Hint 2/3
Use the bitwise AND operation (&) with 1 to check if the least significant bit is 1.
- `n & 1` returns 1 if the last bit is 1, 0 otherwise
- Use `n >> 1` to shift right by 1 bit

## Hint 3/3
Optimization trick: `n & (n-1)` removes the rightmost set bit. Keep doing this until n becomes 0 and count the iterations.

## Solution
```go
func hammingWeight(num uint32) int {
    count := 0
    for num != 0 {
        count++
        num = num & (num - 1)  // Remove rightmost set bit
    }
    return count
}
```
